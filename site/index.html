01 / 它解决的事

四大功能，一个工具搞定

换个账号，之前做的事就断了
说一句「继续做那个项目」，新账号自己找到上次干到哪，接着往下干。
开个新会话，不知道上周做到哪了
对话、它搜了什么、跑了什么命令，一字不落地存着，随时查得到。
聊得太久，早先的细节就丢了
完整记录在本地库里，上下文被压缩了也不怕，需要时它自己来查。
「当初为什么这么改？」想不起来

03 / 三步上手

装完就不用管

Windows 用户看下面「Windows 安装」四步；苹果电脑看最下面的「Mac 版」两步。

Windows 安装 · 双击安装包
STEP 01

装好

双击安装包，桌面多一个图标。不用装别的东西。

STEP 02

粘一句话

打开页面，复制现成的那句话，粘给 WorkBuddy，发送。

STEP 03

不用管了

后台每 30 分钟自动收一次。以后直接问 WorkBuddy。

STEP 04

正常使用

只要你用 WorkBuddy 做过的事情，任意会话问它，它都知道，再也不需要换号找记录了。

macOS 安装 · 仅限苹果电脑 Windows 用户请跳过这一块

苹果电脑用这两步 （Windows 用户看上面四步）

第一步：先装 Node.js（22 或更高）
到 nodejs.org 下载 macOS 安装包，双击装完。已经装过就跳过这一步。

第二步：打开「终端」，粘贴这一行，回车

curl -fsSL "https://gitee.com/gaogao2013/Buddy-Trace/raw/master/scripts/install-mac.sh" -o /tmp/bt-install.sh && bash /tmp/bt-install.sh

装完会自动打开浏览器界面，剩下的跟 Windows 一样。

权限：Mac 版需要「完全磁盘访问权限」。首次运行如果系统弹出提示，到 系统设置 → 隐私与安全性 → 完全磁盘访问权限，把「终端」勾上放行即可。

更新：Mac 版不自动更新，重跑第二步那条命令即可。
